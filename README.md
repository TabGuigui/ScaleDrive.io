# ScaleDrive project page

An academic project page for **Scaling Action-Free Video Latent Prediction for Transferable Representations in End-to-End Autonomous Driving** (anonymous ICLR 2027 submission).

This is a buildless static site. Open `index.html` locally or serve this repository root with any static file server. Figures are exported from the manuscript assets in the accompanying research workspace. The page keeps the manuscript's anonymous-review status and reports only results stated in the manuscript.

The design takes structural inspiration from the widely used [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) and [Nerfies](https://github.com/nerfies/nerfies.github.io), but uses original HTML, CSS, and artwork.
